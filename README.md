# 🔥💧Avatar VR Game: Using Gestures to bend the elements🍃🪨
This a continuation of my University Final-Major-Project, wherein, I created an input system
that just takes the pose a person is making in VR and uses that to activate different abilities.

Using this system I've created gameplay akin to the Benders in the series "Avatar the Last Airbender", 
where you use martial arts to throw rocks, spew fire and control bodies of water.

## Installation
### Unity Project
- Open Unity Hub
- Ensure you have at least Unity ```6000.1.11f1```
- Download the ```VR Game``` file
- Click the Add button and locate the file
- Open the project
